 デザイン システム プライバシー onChromeOS について

設定

onChromeOS の動作や見た目をカスタマイズできます。

デザイン

dark_mode
テーマ
明るさに合わせて外観を切り替えます。
wallpaper
壁紙
ホーム画面の背景を設定します。

システム

notifications
通知
アプリやシステムからの通知を許可します。
animation
アニメーション
ウィンドウや UI のアニメーションを有効にします。
language
言語
設定ページで使用する言語です。

プライバシー

database
ローカルデータ
このブラウザに保存された onChromeOS の設定を管理します。

onChromeOS について

laptop_chromebook
onChromeOS
Web technologies で作られた ChromeOS 風デスクトップ環境です。
設定画面もホーム画面と同じ onChromeOS のウィンドウ・サーフェス・カラー体系を使用しています。
